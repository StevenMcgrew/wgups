This project is designed to solve a fictional "UPS" delivery problem where there is a hub that has two or more delivery trucks with many packages to deliver to many different addresses around Salt Lake City. Some of the packages are priorty (meaning they need to be delivered by a specific time) while others are standard and only need to be delivered by the end of the day. Also, some of the packages are delayed and won't arrive to the hub until later in the day. The task is to design an algorithm that delivers all of the packages on time and in the most efficient way you can.
